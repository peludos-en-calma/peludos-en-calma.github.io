# Peludos en Calma — лендинг

Сайт: **https://peludos-en-calma.github.io/**

Готовый сайт лежит в `site/`: главная `index.html`, юридические страницы `aviso-legal.html`, `privacidad.html`, `cookies.html`, папки `img/` и `fonts/`, `sitemap.xml` и `robots.txt`. При каждой отправке изменений в ветку `main` GitHub Actions (`.github/workflows/pages.yml`) заново собирает страницы из `src/` и публикует папку `site/` на GitHub Pages. Ход публикации виден во вкладке Actions репозитория.

## Языки

- По умолчанию сайт открывается на испанском. Испанский текст записан прямо в HTML, его видят поисковики и посетители без JavaScript.
- Переключатель ES / RU / TR / EN в шапке меняет все тексты без перезагрузки.
- Ссылка на конкретный язык: `index.html?lang=ru`, `?lang=tr`, `?lang=en`.

## Как поменять текст

- Тексты главной — `src/i18n.json`, юридические тексты — `src/legal.json`. В каждом четыре блока: `es`, `ru`, `tr`, `en`, структура у всех одинаковая.
- Данные владельца (имя, NIF/NIE, адрес, email, телефон), адрес онлайн-опросника и название ИИ-сервиса — `src/owner.json`. Они подставляются во все юридические тексты на всех языках.
- Вёрстка главной — `src/template.html`, юридических страниц — `src/legal.html`, общие стили (шапка, кнопки, подвал) — `src/base.css`. Текст в шаблоны не пишется: у элементов стоит `data-i18n="ключ"`.
- Шрифты (Nunito, Playfair Display, Unbounded) лежат в `site/fonts/` вместе с лицензиями OFL и подключаются из `src/fonts.css`, без обращений к Google.

Отправьте изменения в `main`, и сайт пересоберётся сам. Чтобы проверить сборку у себя (нужен Node.js 18+):

```bash
node tools/build.mjs
```

Сборка проверяет, что у всех четырёх языков одинаковые ключи и одинаковое число пунктов, и останавливается с ошибкой, если что-то не совпадает.

## Что осталось заполнить

- `src/owner.json`: вместо `[NIF]`, `[DOMICILIO]` и `[EMAIL]` впишите настоящие NIF/NIE, адрес и email. Без них Aviso legal не соответствует ст. 10 LSSI-CE.
- `src/owner.json`: вместо `[PROVEEDOR IA]` впишите ИИ-сервис, который обрабатывает ответы опросника (например, «OpenAI, L.L.C.»). Он упоминается в политике конфиденциальности.
- Фото Ирины для блока «Sobre mí» (сейчас заглушка «Aquí irá la foto»).
- Юридические тексты составлены как шаблон по LSSI-CE, RGPD и LOPDGDD. Перед запуском их стоит показать юристу.
