# Bienestar Animal — лендинг

Сайт: **https://peludos-en-calma.github.io/**

Готовый сайт лежит в `site/`: `index.html` и папка `img/`. При каждой отправке изменений в ветку `main` GitHub Actions (`.github/workflows/pages.yml`) заново собирает `site/index.html` из `src/` и публикует папку `site/` на GitHub Pages. Ход публикации виден во вкладке Actions репозитория.

## Языки

- По умолчанию сайт открывается на испанском. Испанский текст записан прямо в HTML, его видят поисковики и посетители без JavaScript.
- Переключатель ES / RU / TR / EN в шапке меняет все тексты без перезагрузки.
- Ссылка на конкретный язык: `index.html?lang=ru`, `?lang=tr`, `?lang=en`.

## Как поменять текст

1. Исправьте строку в `src/i18n.json` (там четыре блока: `es`, `ru`, `tr`, `en`, ключи у всех одинаковые).
2. Если меняется вёрстка, правьте `src/template.html`. Текст в шаблон не пишется: у элементов стоит `data-i18n="ключ"`.
3. Пересоберите страницу (нужен Node.js 18+):

```bash
node tools/build.mjs
```

Сборка проверяет, что у всех четырёх языков есть все ключи, и останавливается с ошибкой, если какого-то не хватает.
